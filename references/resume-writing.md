# Resume Writing Guide

Use this reference when producing resume sections or rewriting content.

## Resume Story

Build a clear role narrative:

`past capability -> current specialization -> target role fit`

Examples:

- `complex interaction systems -> data growth -> AI Agent / platform PM`
- `hardware information entry -> AI processing platform -> knowledge workflow`
- `developer/user marketplace -> platform governance -> Agent ecosystem`

The first screen should make the target role obvious.

## Bullet Formula

Use compact bullets with this pattern:

`ownership + product object + mechanism + user/business/model result`

Optional add-ons:

- metric or evaluation signal
- collaboration scope
- technical/tool context
- platform/admin/governance scope

## Strong Bullet Types

- **0-1**: define product from vague problem to launched workflow.
- **Scenario**: connect user pain, core path, and product mechanism.
- **Iteration**: show data/feedback/model quality loops.
- **Platform**: show lifecycle, permissions, governance, marketplace, developer/user sides.
- **Growth**: show acquisition, activation, retention, conversion, pricing, or monetization.
- **Technical fluency**: show API, Tool Use, prototype, model eval, coding, MCP, prompt/context work.

## Rewrite Rules

- Lead each experience with scope and title: `Product Owner`, `Module Owner`, `Growth PM`, `Interaction Designer`.
- Use domain nouns early: `Agent Template`, `Skill Market`, `AI knowledge base`, `open API`, `admin console`.
- Replace broad examples with category terms: use `intelligent workflow` instead of long lists of HR/finance/product/dev templates.
- Keep each bullet one or two lines when possible.
- Avoid "helped", "participated", "responsible for daily..." unless ownership was truly limited.
- For unknown metrics, write metric categories instead of fake numbers: `retention`, `subscription conversion`, `knowledge base retention`, `model quality metrics`.

## Suggested Modules

For AI/Agent PM roles, prefer:

1. Header: name, target title, phone/email, portfolio, GitHub.
2. Positioning summary: 2-3 lines max.
3. Work experience: newest and most relevant first.
4. Optional keywords strip: only if it reads naturally and has evidence below.
5. Education: compact, with relevant technical/design courses.
6. Projects/GitHub: include only if they add proof not already in work experience.

## Good AI/Agent Resume Phrases

- `将模型能力转化为低门槛、可配置、可持续使用的产品体验`
- `从单次任务处理演进为长期知识管理`
- `将通用任务沉淀为可复用智能工作流`
- `使 Agent 从固定模板扩展为可配置、可组合的能力容器`
- `覆盖制作、上架、审核、下架、应用与反馈闭环`
- `围绕转写完成率、内容消费、订阅转化、留存等指标确定 Roadmap 优先级`
- `联合算法团队优化专业词汇召回、声纹切分、跨语种对齐等模型质量指标`

## Common Fixes

- If content is too long: keep the top two bullets per project and compress the rest into tags.
- If content feels empty: add product object, user scenario, data signal, or decision mechanism.
- If content feels too technical: connect technical terms back to user value or product workflow.
- If content feels too generic: add the exact module name and ownership scope.
