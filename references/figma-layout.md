# Figma Resume Layout Guide

Use this reference when editing or advising on Figma resume layouts.

## Layout Goal

Make the first 5 seconds answer:

1. Who is this person?
2. What role are they applying for?
3. Why are they credible for this exact JD?
4. Where is the strongest proof?

## Recommended Structure

- A4 frame.
- Header with portrait only if it improves recognition and does not consume proof space.
- Name and target title on the left or center-left.
- Contact links grouped on the right.
- Summary in a light band or compact paragraph.
- Experience as the main body, with clear section dividers.
- Left-side tags for bullet type: `0-1`, `场景`, `迭代`, `数据`, `Agent`, `Skill`, `生态`, `后台`, `增长`, `转化`.
- Education at bottom, compact.

## Visual Hierarchy

- Name: largest text, high contrast.
- Target title: accent color, one line if possible.
- Section title: accent color with horizontal rule.
- Company/title line: bold.
- Project/module line: slightly smaller but still prominent.
- Body bullets: regular weight, enough line height for dense Chinese text.
- Tags: small rounded pills, consistent width, low-saturation background.

## Spacing Rules

- Use consistent left alignment for all body text.
- Keep tag column width fixed; align tag center vertically with bullet first line.
- Keep bullets visually separated by 6-10 px depending on font size.
- Use section dividers to separate companies, not heavy cards.
- Avoid nested cards in resumes.
- Keep education compact; it should not compete with current work experience.

## Text Rules

- Do not let a single line run too long if it becomes hard to scan.
- Use `｜` consistently in titles.
- Avoid mixed extra spaces around separators, e.g. prefer `TicNote｜Agentic AI 知识平台｜软件产品负责人`.
- Use link text that is visible and useful: portfolio, GitHub, project repo, product URL.
- If a link points to a product, make the product name clickable rather than adding a long raw URL in the body.

## Figma Link Instructions

To add a clickable URL manually:

1. Select the text or layer.
2. Press `Command + K`.
3. Paste the URL.
4. Confirm the link.
5. Export PDF and test the link.

Use product links for product names when helpful, e.g. `TicNote` -> `https://ticnote.com`.

## Using Figma MCP

When Figma tools are available:

- Inspect selected frame and relevant text nodes before editing.
- Preserve the user's design direction; adjust hierarchy and spacing rather than rebuilding without need.
- Apply changes incrementally: typography, line height, alignment, link targets, then export/readback QA.
- If MCP is rate-limited or unavailable, provide exact manual Figma instructions and continue with text QA.

## Export Guidance

- Export as PDF for sending.
- Check that text remains selectable.
- Check that links work in the exported PDF.
- Render the PDF to an image and inspect layout at full-page scale.
