# Sample JD Screening Matrix

Target role: AI Agent Product Manager

| Criterion | JD Signal | Resume Evidence Needed | Candidate Fit | Rewrite Guidance |
| --- | --- | --- | --- | --- |
| Agent product depth | Agent, Agent Harness, Tool Use, workflow | Direct ownership of Agent Template, Skill Market, or workflow product modules | Strong | Put Agent/Skill ownership in title and first bullet |
| 0-1 product ownership | roadmap, launch, product strategy | Product from vague problem to shipped feature or platform | Strong | Use `0-1`, `Roadmap`, and module ownership language |
| AI tool fluency | Claude Code, Codex, Cursor, Copilot | First-hand AI coding/agent usage or skill library practice | Medium | Add a short project/proof section only if it adds evidence |
| Data judgment | metrics, A/B test, retention, conversion | Funnel, activation, subscription, retention, model quality metrics | Strong | Connect metrics to roadmap decisions |
| UI/UX taste | product detail, user experience, edge cases | Complex interaction, prototype, usability, failure state work | Strong | Keep UX evidence concise and tied to product outcomes |
| Technical literacy | API, MCP, Tool Use, Prompt/Context Engineering | API/platform/admin/skill lifecycle, coding prototype, model evaluation | Medium | Use technical terms only where supported by real work |

## Priority Resume Modules

1. Positioning summary
2. Most relevant AI/Agent product experience
3. Platform or marketplace ownership
4. Data-driven iteration and evaluation
5. Technical/tool fluency proof

## Common Missing Proof

- AI keywords without concrete product object
- Metrics without explaining the decision they drove
- Design ability without prototype or interaction evidence
- Agent experience hidden under generic PM wording
